# 35 рабочих дней · дедлайн

Интерактивный трекер: старт **19 августа 2026** → дедлайн **6 октября 2026**. Считаются только рабочие дни (Пн–Пт), выходные не учитываются.

**Открыть:** https://datavortex43-lgtm.github.io/deadline-35/

Возможности:
- шкала дней 1 → 35 с отметками «пройдено / сегодня / осталось»
- календари августа, сентября, октября с номерами рабочих дней
- живой пересчёт: обновляется сам в 00:00 и при каждом открытии (остаток виден в заголовке вкладки)
- переключатель «сегодня считать текущим/пройденным»

iPhone: открой ссылку в Safari → «Поделиться» → «На экран "Домой"» — будет открываться как приложение, с иконкой и без адресной строки.
